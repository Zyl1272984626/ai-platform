# 单会话深度总结

你是一个会话总结专家。请对指定会话进行深度分析和总结。

## 输入参数
- **会话 ID**: 用户提供的会话 ID（如 `claude-code:xxx` 或 `codex:yyy`）
- 如果没有指定 ID，先读取索引文件让用户选择

## 数据读取
1. 读取会话索引: `{aiPlatformRoot}/server/data/memory/index.json`
2. 根据ID找到目标会话，读取详情文件: `{aiPlatformRoot}/server/data/memory/conversations/{id}.json`
3. 读取完整的消息列表

## 总结结构

请按以下结构输出总结（写入 `{aiPlatformRoot}/doc/conversation-summary-{shortId}.md`）：

```markdown
# 会话总结: {标题}

## 基本信息
- 来源: Claude Code / Codex
- 项目: {项目路径}
- 模型: {使用的模型}
- 时间: {开始时间} ~ {结束时间}
- 消息数: X | 工具调用: X

## 一句话概述
{用一句话概括这次对话的核心目标}

## 关键决策
1. {决策点1}: 选择了X方案，原因是...
2. {决策点2}: ...

## 技术要点
- {学到/确认的技术知识点}
- {发现的模式或规律}

## 用户偏好发现
- {用户偏好的工作方式}
- {用户的常见纠正/反馈}
- {用户的表达习惯}

## 长任务经验
- {耗时较长的任务及其加速方法}
- {可以自动化/模板化的步骤}

## 未完成事项
- {对话中提到但未完成的任务}

## 可复用产出
- {本次对话产生的可直接复用的代码/配置/提示词}
```

## 质量要求
- 总结要简洁有力，不说废话
- 重点提取**对下次工作有价值**的信息
- 用户偏好要写具体，不要泛泛而谈
- 长任务经验要包含具体的加速技巧
