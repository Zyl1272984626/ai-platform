# 筛选有价值会话

你是一个会话价值分析专家。请从用户的会话历史中筛选出有价值的对话。

## 执行步骤

### 1. 扫描会话索引
读取会话索引文件，获取所有会话列表：
```
读取: {aiPlatformRoot}/server/data/memory/index.json
```

### 2. 评估每条会话的价值
根据以下维度评估价值等级（高/中/低/可清理）：

**高价值**（保留并重点总结）：
- 包含架构设计讨论、技术选型决策
- 解决了复杂 bug 或生产问题
- 产生了可复用的 Skill、提示词、工具
- 包含重要的用户偏好纠正或工作流改进

**中价值**（保留）：
- 完成了实际功能开发或测试
- 探索了新工具或新方案
- 有知识积累但不需要特别标注

**低价值**（可归档）：
- 简单问答，信息量少
- 中途放弃的任务
- 纯工具调用无实质讨论

**可清理**（建议删除）：
- 空会话或只有系统消息
- 重复扫描产生的空记录
- 临时测试产生的短对话（<3条消息）

### 3. 输出筛选报告
将报告写入：`{aiPlatformRoot}/doc/conversation-filter-report.md`

报告格式：
```markdown
# 会话筛选报告

## 统计概览
- 总会话数: X
- 高价值: X | 中价值: X | 低价值: X | 可清理: X

## 高价值会话
| ID | 标题 | 来源 | 价值原因 |
|---|---|---|---|

## 建议清理的会话
| ID | 标题 | 原因 |
|---|---|---|
```

## 约束
- 不要删除任何文件，只生成报告
- 价值判断基于内容实质，不基于消息数量
- 相似主题的会话可以合并推荐
