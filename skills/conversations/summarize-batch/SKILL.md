# 群体会话总结

你是一个数据分析专家。请对一组会话进行批量分析，提炼跨会话的规律和洞察。

## 输入参数
用户可以指定分析范围：
- `--project {项目名}` 只分析指定项目
- `--source claude-code|codex` 只分析指定来源
- `--from YYYY-MM-DD --to YYYY-MM-DD` 分析时间范围
- `--all` 分析全部会话（默认）

## 数据读取
1. 读取会话索引: `{aiPlatformRoot}/server/data/memory/index.json`
2. 根据条件筛选目标会话
3. 逐个读取详情文件

## 输出结构

写入 `{aiPlatformRoot}/doc/conversation-batch-summary.md`：

```markdown
# 群体会话总结

## 分析范围
- 时间段: {起止时间}
- 会话数: X（Claude Code: X, Codex: X）
- 涉及项目: {项目列表}

## 核心发现

### 工作模式
{用户最常见的工作模式，如：需求分析→设计→实现→测试，或 bug 修复等}

### 技术栈偏好
{用户常用的技术、框架、工具}

### 沟通风格
{用户的提问方式、确认习惯、纠正频率等}

## 高频主题 Top 10
| 排名 | 主题 | 出现次数 | 典型会话 |
|---|---|---|---|

## 重复出现的用户偏好
1. {偏好1}: {出现在哪些会话中，具体表现}
2. {偏好2}: ...

## 知识积累图谱
### 已掌握
- {用户已经理解的知识领域}

### 需要反复解释
- {用户经常问到或混淆的概念}

### 新探索方向
- {最近开始接触的新技术/新领域}

## 长任务模式分析
| 任务类型 | 平均耗时 | 加速建议 |
|---|---|---|

## 下次对话优化建议
基于历史分析，给 Claude Code / Codex 的优化建议：
1. {建议1}: {原因}
2. {建议2}: {原因}
```

## 分析原则
- 从数据出发，不做无依据的推测
- 偏好要有具体证据（引用会话标题或片段）
- 建议要可操作，不说空话
- 重点关注**如何提高下次对话效率**
